# Instrucciones del proyecto

## Frontend de Mercado

Para cualquier creación o modificación dentro del módulo Mercado:

1. Usar la skill `$mercado-neobrutal-angular`.
2. Leer `.agents/skills/mercado-neobrutal-angular/references/ITEMS.md`.
3. Inspeccionar las imágenes ubicadas en:
   `.agents/skills/mercado-neobrutal-angular/assets/`.
4. Tomar `mercado-desktop-aprobado.png` como referencia visual principal.
5. Reproducir la interfaz mediante Angular y SCSS; no insertar el mockup como imagen.
6. Mantener el estilo arcade oscuro y neobrutalista aprobado.
7. No utilizar bordes redondeados, sombras suaves, gradientes,
   glassmorphism, Angular Material, Bootstrap ni Tailwind.
8. Antes de finalizar, ejecutar el proyecto y comparar visualmente
   el resultado con la referencia aprobada.
